# BlinkIT Grocery Sales Analysis

## Project Overview
This project focuses on analyzing BlinkIT grocery sales data to identify sales trends, understand outlet performance, and generate useful business insights.

## Objectives
- Understand overall grocery sales performance.
- Clean and validate the dataset.
- Analyze sales by item type and outlet type.
- Identify top-performing and low-performing items.
- Explore relationships between numerical variables.
- Generate business recommendations.

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- VS Code

## Dataset
The dataset contains grocery item details, outlet information, sales, item visibility, item weight, and customer ratings.

## Analysis Performed
1. Data loading and exploration
2. Missing value treatment
3. Duplicate record validation
4. Sales analysis
5. Item type analysis
6. Outlet performance analysis
7. Rating analysis
8. Item visibility analysis
9. Correlation analysis
10. Top and bottom selling item analysis

## Project Files
- `blinkit_analysis.py` – Python analysis code
- `BlinkIT Grocery Data.xlsx` – Original dataset
- `BlinkIT_Cleaned_Data.csv` – Cleaned dataset
- `README.md` – Project documentation

## Conclusion
This analysis helps understand grocery sales patterns and outlet performance. The findings can support better inventory planning, product visibility, and business decision-making.
